    What Beamline is, and what it gives up

    • Persists an ordered edge list, nothing else. The graph container (#graph) carries one attribute, data-edges, holding a JSON array of [from, to] node-id pairs in the order they were connected. No node carries an x, a y, a column or a slot index — position on screen is a pure function of the order nodes were added, laid out by ordinary flex flow. verify.py --beamline reads that attribute and prints it back as ordered source→destination pairs; see its own comment for the check that no coordinate exists anywhere in the DOM either.
    • Connects by clicking, not dragging. Click an output port to arm it, then click an input port on a different node to attempt the connection. A drag gesture between two ports produces no click event on either one, so it is refused by construction rather than by a special case that watches for it.
    • The trade this style makes, on purpose. Beamline gives up all arrangement agency — a student cannot place a node anywhere, cannot express "these two belong near each other" spatially, and the graph never needs a canvas wider than the rail. That is also its strongest asset: at narrow widths the rail simply wraps, so this is the only one of the three styles with a real story at 768 px rather than a compromise at it.
    • Node-kind colour, not wire colour. Each of the 8 addable kinds owns a hue on its own chrome (tokens.css's --node-* set); there is no drawn wire to colour, since connections are represented as text (→ Selection (n3)) rather than a drawn line — a deliberate consequence of persisting no coordinate, since a drawn connector would need one to place its endpoints even if that placement were never saved.
    • Locked node kind. The palette's final tile is not one of the 8 addable kinds — it stands for a node type a later mission unlocks, shown so a student can see it is coming. It carries no port, no click handler, and no tab stop, so it cannot be reached as an active control by keyboard or by mouse.

    Nothing on this page ships; it exists to be compared against Bench (D-005, free canvas, drag-to-connect) and Board (D-006, typed columns, both gestures) at the D-007 checkpoint. See verify.py --beamline for what is actually measured about this rendering, rather than claimed here.
