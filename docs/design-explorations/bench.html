What Bench is, and what it gives up

  • Persists an {x, y} pair per node, plus the edge list. The canvas container (#graph) carries one attribute, data-ui, holding a JSON object shaped { nodes: [{id, x, y}], edges: [[from, to]] } — the same object design-brief.md §4 calls the run payload's own "ui object", the part the engine never reads. Node kind is not in it: that stays on the node's own element (data-node-kind), the same place Beamline puts it, because kind is analysis content and position is not. verify.py --bench reads this attribute after a real drag, not just at load, so the claim covers a moved node, not only a spawned one.
  • Connects by dragging, not clicking. Press down on an output port, move the pointer, and release over an input port on a different node. No port carries a click listener — Bench's Enter/Space keyboard path runs through keydown instead, specifically so a plain mouse click (which a native <button> would otherwise turn into a synthetic click event on activation) triggers no handler and therefore no connection, the mirror image of how beamline.js's own comment describes a bare click listener making a drag gesture inert there.
  • No inline style= attribute, anywhere. Continuous, freely-dragged position needs some way to place an element outside a fixed set of CSS classes; Bench answers that with SVG geometry rather than CSS — each node is a <foreignObject> whose x/y are plain attributes bench.js sets directly, never a style property. The HTML content painted inside that foreignObject (the node card, its ports) is styled by class exactly like anything else on the page.
  • The trade this style makes, on purpose. Bench gives up the guarantee that a graph reads the same way twice — two students building an identical pipeline can leave it looking entirely different — in exchange for spatial arrangement being a real tool: grouping related nodes, spreading a wide pipeline out, matching a diagram from class. Its connectors are drawn lines, not text, because a coordinate already exists to anchor them — the opposite trade-off from Beamline, which drew no wire because it kept no coordinate to place one against.
  • Locked node kind. The palette's final tile is not one of the 8 addable kinds — it stands for a node type a later mission unlocks, shown so a student can see it is coming. It carries no port, no click handler, and no tab stop, so it cannot be reached as an active control by keyboard or by mouse.

Nothing on this page ships; it exists to be compared against Beamline (D-004, single rail, click-to-connect) and Board (D-006, typed columns, both gestures) at the D-007 checkpoint. See verify.py --bench for what is actually measured about this rendering, rather than claimed here.
