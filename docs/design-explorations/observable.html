The merged Observable node

Ruled 2026-09-02 (docs/design-brief.md §4): the four Obs* subtypes the reference engine defines — ObsGlobal, ObsObject, ObsVectorSum, ObsCustom — are one palette node, not four. A student places a single Observable node and picks a mode inside it; the mode is config, not identity, and resolves to the engine's subtype at submit, exactly as DataSource is synthesised at submit. Nothing about which graphs are legal changes — every mode shares the same legal connection, Observable* → Histogram, which is why merging the node costs nothing structurally.

D-009 shipped the four subtypes as four separate node interiors, in the inline-grow treatment among others — the node card itself grows in place to hold its form, rather than opening a separate flyout panel. This page continues that treatment for the merged node only: one node, a mode toggle inside it, and the four control sets D-009 already designed, now switched rather than duplicated. Opened height per mode is measured at the bottom — this is the widest node in the four-kind palette, so its footprint is the number D-010 sizes the palette shell against.

Observable

One node, one config: {mode, ...mode's own fields} in the run payload — the mode names above (ObsGlobal, ObsObject, ObsVectorSum, ObsCustom) are values of that field, never a node kind a student chooses at placement time. Try the toggle above: it is a native radio group, each option individually reachable by Tab and activated with Space, and only the active mode's controls render — the switch is plain CSS (:has() against the checked radio), no script.

How a locked mode reads

Under the merged node, ObsVectorSum — the mission-2 unlock, adding the photon's four-vector back to recover the Z mass — cannot read as a fifth palette button that simply is not there yet, because it no longer is one; the unlock has to read inside the node. The toggle option above is where it happens: before mission 2 is reached, that option carries the same desaturated, visibly-inert treatment .claude/design/CLAUDE.md §2 asks of every locked node kind — not a lighter grey, a distinct flat fill — plus a small lock glyph in place of the mission tag, and it drops out of the tab order rather than sitting in it disabled-and-silent, so a keyboard student's Tab press skips straight past it to the next real option. This mock is aria-hidden and inert; the live toggle above stays fully unlocked so every mode is testable on this page.
